# W2-PM5 – Network Scanning Using Zenmap

## Internship Module
**Networkwalks Cybersecurity Internship Programme**

## Objective
To understand network scanning, live host discovery, IP address identification, MAC address documentation, and network topology visualization using Zenmap.

## Tools Used
- Zenmap
- Nmap
- Windows 11 Command Prompt

## Practical Activities

| No. | Activity |
|---|---|
| 1 | Local network configuration |
| 2 | Scan configuration |
| 3 | Live host discovery |
| 4 | Host identification |
| 5 | MAC address identification |
| 6 | Network topology generation |

## Documentation
The detailed practical report and supporting evidence are maintained separately.

## Disclaimer
Network scanning was conducted on the local network for educational purposes. Network information and device identifiers must be sanitized before public disclosure.
