# W2-PM5 – Network Scanning Using Zenmap

## Internship Programme
**Networkwalks Cybersecurity Internship – Batch B084**

## Objective
To perform network scanning, identify live hosts, record network configuration details, and visualize network topology using Zenmap.

## Tools Used
- Zenmap
- Nmap
- Windows 11 Command Prompt

| 6 | Network topology generation |
